# 🚀 5-Minute Quickstart Guide

This guide walks you through building an agent with `lughus` in 5 minutes, progressing from a simple script to an enterprise-ready A2A server.

---

## 1. Installation

Install `lughus` using `pip`:

```bash
# Standalone core (LiteLLM, JSON Schema validation, python-dotenv)
pip install lughus

# Or full stack (FastAPI, uvicorn, A2A SDK, OpenTelemetry)
pip install "lughus[all]"
```

---

## 2. Track 1: Standalone Agent Loop in 30 Seconds

A complete agent loop in a single file without spinning up a server:

```python
import asyncio
import json

from lughus import ToolRegistry, agent_loop
from lughus.testing import MockLLM

# 1. Create a tool registry
registry = ToolRegistry()


@registry.tool(
    "calculate",
    "Perform a mathematical calculation.",
    {
        "type": "object",
        "properties": {
            "expression": {"type": "string", "description": "Expression, e.g. 2 + 2"},
        },
        "required": ["expression"],
        "additionalProperties": False,
    },
)
def calculate(*, expression: str, state) -> str:
    # Safe evaluation for demonstration
    return json.dumps({"result": eval(expression, {"__builtins__": None}, {})})


# 2. Mock LLM for offline testing (or swap with LLM(model="openai/gpt-4o"))
llm = MockLLM(
    [
        [{"name": "calculate", "arguments": {"expression": "21 * 2"}, "id": "call_1"}],
        "The result of 21 * 2 is 42.",
    ]
)


# 3. Execute the loop
async def main():
    result = await agent_loop(
        llm,
        system="You are a math assistant. Use the calculate tool.",
        context="What is 21 * 2?",
        registry=registry,
        tool_names=["calculate"],
    )
    print(result)
    print(f"Iterations: {result.iterations}, Total tokens: {result.total_tokens}")


asyncio.run(main())
```

To run with a live provider (OpenAI, Anthropic, Gemini, DeepSeek), swap `MockLLM` for `LLM`:

```python
from lughus import LLM

llm = LLM(model="openai/gpt-4o")
```

## 3. Adding Tool Guardrails & Governance

Tools can declare deterministic risk tiers, required permission scopes, and approval gates:

```python
import json

from lughus import ToolEffect, ToolRegistry, ToolRisk

registry = ToolRegistry()


@registry.tool(
    "delete_database_record",
    "Permanently delete a record by ID.",
    {
        "type": "object",
        "properties": {"record_id": {"type": "string"}},
        "required": ["record_id"],
    },
    risk=ToolRisk.CRITICAL,
    effects=frozenset([ToolEffect.WRITE, ToolEffect.IRREVERSIBLE]),
    requires_approval=True,  # Blocks execution until approved
)
def delete_record(*, record_id: str, state) -> str:
    return json.dumps({"deleted": record_id})
```

## 4. Track 2: Production A2A Server in 2 Minutes

When your agent needs to serve requests over the network, handle streaming, and expose the **Developer Console**:

### Step 1: Scaffold an agent

```bash
lughus new math_agent
cd math_agent
pip install -e ".[dev]"
```

### Step 2: Configure environment

Create your `.env` file:

```bash
cat << 'ENVEVAL' > .env
AGENT_MODEL=openai/gpt-4o
OPENAI_API_KEY=sk-...
ENABLE_CONSOLE=true
HOST=0.0.0.0
PORT=8080
ENVEVAL
```

### Step 3: Run the server

```bash
python -m math_agent
```

### Step 4: Open Developer Console

Open `http://localhost:8080/ui` in your browser. You get:
- **Interactive Execution**: type objectives and send with `Ctrl+Enter`.
- **Live Timeline**: step-by-step visual execution flow (Agent Path).
- **Rich Output**: Markdown tables, GitHub alert callouts (`[!NOTE]`, `[!WARNING]`), and KaTeX LaTeX formulas.
- **Human-in-the-loop**: approve or reject critical tool calls live with actionable approval cards.
- **Artifact Downloads**: inspect and download files generated by the agent.
